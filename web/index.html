TrendLens Platform

v3.4 Production • BSCS FYP

Multi-Genre AI-Powered Visual Trend Analysis & Forecasting

TrendLens is an end-to-end computer vision platform designed for granular visual intelligence across fashion apparel and automobile styling. Developed as a BSCS Final Year Project by Hamza Khalid.

Core Machine Learning & Engineering Stack
Backbone Architecture: PyTorch ResNet-18 (512D L2-Normalized Vectors)
Similarity Engine: Cosine Proximity (1.4ms In-Memory Retrieval)
Unsupervised Clustering: K-Means & Agglomerative Cluster Analysis
Time-Series Forecaster: Meta Prophet (Bayesian Changepoint Inference)
Backend Pipeline: Python 3.12 + FastAPI Async Server
Local Session Security: Ephemeral Memory Inference + Encrypted Browser Storage
100% On-Premise Execution: No camera images or telemetry leave your local machine during evaluation or testing.
