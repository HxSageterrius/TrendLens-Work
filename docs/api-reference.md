# TrendLens — REST API Reference

Base URL: `http://127.0.0.1:8000` — all endpoints are same-origin with the dashboard.
Interactive docs: `/docs` (Swagger UI, generated by FastAPI).

All data endpoints accept `?genre=fashion` (default) or `?genre=automotive`. Unknown genre
values are treated as fashion.

## Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/` | Serves the web dashboard (`web/index.html`) |
| GET | `/api/health` | Readiness flags + catalog/embedding sizes per genre |
| GET | `/api/trends/summary?genre=` | Per-style trajectory summary (Prophet or statistical fallback). Automotive returns a structured `forecasting_disabled` placeholder. |
| GET | `/api/trends/forecast?genre=&style=&horizon=` | Forecast points with 90% CI for one style. `horizon` clamped to 4–26 weeks. 404 for unknown style. |
| GET | `/api/clusters?genre=` | Cluster summaries for the active genre (JSON cache with on-disk fallback). |
| GET | `/api/runs` | Available pipeline runs; benchmark titles derived from committed artifacts. |
| GET | `/api/runs/{run_id}/clusters` | Cluster detail for `fashion-benchmark`, `automotive-benchmark`, or a scraped reference run. |
| GET | `/api/items?genre=&style=&category=&limit=` | Catalog items with optional filters (alias: `/api/catalog`). |
| GET | `/api/items/{item_id}?genre=` | One item + top-4 similar items (cross-genre fallback lookup). |
| GET | `/api/data-sources` | Dataset provenance metadata with live counts. |
| GET | `/api/dashboard/summary` | Aggregated KPIs for the dashboard header cards. |
| POST | `/api/similarity/match` | Visual search. Multipart `file` upload **or** `?item_id=`; `?top_k=` 1–12; `?genre=`. Returns ranked matches + `predicted_attributes`. Uploads limited to 10 MB (HTTP 413). |

## Error Semantics

| Status | Meaning |
|---|---|
| 400 | Missing/invalid parameters or unreadable image |
| 404 | Unknown style, item, or run id |
| 413 | Upload exceeded `MAX_UPLOAD_BYTES` (10 MB) |
| 503 | Pipeline artifacts not built yet (e.g. similarity engine not loaded) |

## Static Mounts

| Path | Serves |
|---|---|
| `/web` | Dashboard assets (JS/CSS/images) |
| `/images` | Fashion catalog images |
| `/automotive-images` | Automotive smoke-test images |
| `/data` | Catalog file paths as URLs (used by `resolveImagePath` for thumbnails). Intentional for the local demo — do not expose the server publicly. |
| `/reference-images/{original,segmented}` | Scraped reference-run images (present only if the reference repo exists) |

## Rate/Scale Notes

- Cosine matching is a brute-force scan — fine for N ≤ 45; add an ANN index before scaling.
- Prophet forecasts are cached per `(style, horizon)` and invalidated when the trend CSV changes.
- Resource loading happens once per process (thread-safe lazy init).
